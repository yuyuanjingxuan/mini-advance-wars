A zero-dependency turn-based strategy game inspired by GBA's *Advance Wars*. No frameworks, no build step — just open `index.html` and play!

## ✨ Features

| Feature | Description |
|---|---|
| 🗺️ **Geographic maps** | 8×8 / 10×10 / 12×12 / 14×14 / 16×16, mountain ridges, rivers with fords and forest clusters generated by geographic rules, 180°-symmetric with connectivity check; neutral buildings scale with map area (mostly cities, some factories, roughly 4:1), placed symmetrically for fairness |
| 🪖 **9 unit types** | 🪖 Infantry (versatile, can capture) · 🛡️ Heavy (high ATK/DEF, sluggish, anti-vehicle) · 🚙 Recon (blazing-fast scout, weak in combat) · Cannon (CSS-drawn icon, range 2-3) · 🔧 Engineer (1.5× capture + repair) · ⚕️ Medic (heals) · Tank (CSS-drawn icon, assault main force) · 🚀 Rocket (range 3-5, low mobility) · 🚚 Transport (unarmed, carries foot units) |
| 🥾 **Per-unit movement** | Infantry/heavy/engineer/medic all move identically (forest 1/mountain 2); heavy treads (tank/cannon/rocket) are sluggish, forest 3 & no mountains; tires (recon) are nimble, forest 2 & no mountains, no plain penalty; light treads (transport) forest 2 |
| ⚔️ **Weapons & armor** | 5 armor types (unarmored/light/light-armor/heavy-armor/support) × 5 weapon types (small arms/light-armor gun/heavy-armor gun/high-explosive/anti-armor); heavy infantry and tanks are dual-weapon units that switch to a dedicated weapon against vehicles and small arms/machine gun against infantry-type units. Small arms deal much less damage to vehicles; recon can bully infantry but barely dents tanks; high-explosive shells threaten every target without one-shotting anything |
| 🌲 **Terrain effects** | All terrain is CSS-drawn: Forest +20% DEF · Mountain +40% DEF (vehicles blocked) · River impassable (fords passable) · City/Factory +30% DEF · HQ +40% DEF, owned buildings heal 2 HP per turn |
| 🚩 **Building capture** | Advance Wars-style capture: each side's fixed rear HQ/factory/city already belong to that side at kickoff; every other building on the map (scattered neutrals plus the contested city at the center of odd-sized maps) starts neutral; either side can capture a neutral or enemy-held building (including HQ), only infantry/heavies/engineers can capture (engineer 1.5×), stand on a building and wait to build progress (progress = current HP × multiplier, 20 to capture, progress resets when leaving); captured buildings fly your flag and can be taken back; **capturing the enemy HQ wins instantly, losing your own HQ means defeat** |
| 🔧 **Support units** | Engineer can repair an adjacent vehicle +3 HP, medic can heal an adjacent infantry/heavy/engineer +4 HP (eligible targets are highlighted green when selected — click directly, or click the action button first then pick a target; choose freely when several are adjacent); both are unarmored non-combatants with the same low ATK (2) |
| 🚚 **Transport** | Unarmed transport (move 5) carries 1 foot unit (infantry/heavy/engineer/medic) for extra mobility; move onto its tile to board, select it and click Unload, then **pick exactly which highlighted adjacent tile** the rider disembarks to (the rider can still act that turn); cargo is destroyed along with the transport |
| 💰 **Economy & production** | No starting funds — turn 1 immediately settles income from whatever buildings you own at kickoff; +50 per owned building every turn after that; click your empty factory to open the production menu and spend funds on new units (costs follow Advance Wars-style proportions, infantry/engineer/medic cheapest, rocket priciest; new units wait this turn); the enemy saves money and builds too |
| 🛡️ **Heavy's anti-armor weapon** | Heavy infantry carries a dedicated anti-armor weapon against vehicles (1.5× vs light armor, still 0.7× vs heavy armor) and switches to small arms against infantry-type units — the two weapons resolve independently |
| 💥 **Combat system** | 90% hit chance, 9% crit (×1.5), 0.7× counterattack, damage scales with remaining HP; cannon/rocket cannot fire after moving and never counterattack; every hit's base damage is also randomized within ±15%, so the same matchup deals slightly different damage each time |
| 🪖 **Starting troops** | Pick one of four symmetric tiers before starting: None (0 units, pure economy start) · Few (3 units, 1 mandatory infantry + 2 random from infantry/heavy/engineer/medic) · Medium (6 units, 1 mandatory infantry + 5 random from 7 non-tank/rocket types) · Many (9 units, 1 mandatory infantry + 8 random from all types — tanks/rockets can only appear at this tier); spawn points cluster near each side's own HQ |
| ⬆️ **Leveling** | Gain XP from combat (support units: capture +8, repair/heal +6); XP needed rises each level (30/40/50/60) for a smooth curve; level up grants +1 ATK, +1 DEF, +2 HP and heals 3 HP (cap Lv.V, excess XP converts to healing) — enemies level up too! |
| 🔍 **Inspect enemies** | Click an enemy unit to see its move range (translucent blue) and attack range (dashed orange) — know your enemy |
| 🤖 **Enemy AI style** | Pick one of three styles before starting: 🛡️ Balanced (avoids bad trades, retreats low-HP units, prioritizes finishing off weakened targets) · 🔥 Aggressive (maximizes damage/kills regardless of losses) · 🏰 Defensive (prioritizes capturing buildings, doesn't chase you down, turtles instead); all built on the same heuristic scoring damage/kills/terrain/danger, weighted per style |
| �️ **Move path preview** | Hover to see the move path with direction arrows after selecting a unit |
| 🔊 **Sound & BGM** | WebAudio chiptune SFX (per-unit attack/move sounds, crit, destroy, level-up, capture, etc.) + dual-theme BGM: upbeat march for the player, tense minor for the enemy, auto-switching with turn phases (mutable) |
| 📜 **Battle log & unit cards** | Real-time combat log (player blue / enemy red) and detailed unit info panel |
| 🌐 **Bilingual UI** | Choose 中文/English in the main menu (default Chinese); the whole UI translates instantly |
| 📖 **In-game help** | Unit stats table, color legend, terrain effects and combat rules |

## 🎮 How to Play

1. Pick a map size, an **enemy AI style** (Balanced/Aggressive/Defensive), and a **starting troop size** (None/Few/Medium/Many) in the main menu
2. **Goal**: Destroy all enemy units, or capture the enemy HQ (complete the capture while standing on the enemy HQ tile)
3. Click your unit → click a **blue tile** to move → click a **red tile** to attack; click your empty factory to **build new units**
4. Click **End Turn** when done; the enemy AI then acts

> 💡 Forest/mountains grant defense bonuses but slow movement — each unit type has different move costs per terrain (infantry excel in mountains, treads cannot enter mountains); owned buildings heal 2 HP per turn and grant +50 income; cannon/rocket cannot fire after moving — they must wait in place to fire; heavy counters vehicles.

## 🚀 Getting Started

**No build, no install:**

```bash
# Option 1: just open the file
index.html

# Option 2: serve locally
python -m http.server 8765
# then open http://localhost:8765
```

## 📦 Tech

- Pure HTML + CSS + JavaScript (**zero dependencies**, no frameworks, no build step)
- **Single-file architecture**: all styles and scripts (config / i18n / SFX / logic) are embedded in `index.html` — just open and play, no external files needed
- Runs in any modern browser — double-click `index.html` works too (no ES modules / fetch, file:// friendly)
