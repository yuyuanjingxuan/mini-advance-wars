A zero-dependency turn-based strategy game inspired by GBA's *Advance Wars*. No frameworks, no build step — just open `index.html` and play!

## ✨ Features

| Feature | Description |
|---|---|
| 🗺️ **Geographic maps** | 8×8 / 10×10 / 12×12, mountain ridges, rivers with fords and forest clusters generated by geographic rules, 180°-symmetric with connectivity check |
| 🪖 **8 unit types** | 🪖 Infantry (versatile, can capture) · 🛡️ Heavy (high ATK/DEF, anti-vehicle) · 🚙 Recon (fast raider) · Cannon (CSS-drawn icon, range 2-3) · 🔧 Engineer (1.5× capture + repair) · ⚕️ Medic (heals) · Tank (CSS-drawn icon, assault main force) · 🚀 Rocket (range 3-5) |
| 🥾 **Per-unit movement** | Advance Wars style: infantry/heavy/medic forest 1/mountain 2, engineer mountain 1, treads (tank/cannon) forest 2 & no mountains, tires (recon/rocket) plain 2/forest 3 & no mountains |
| ⚔️ **Type matchups** | Full damage multiplier table (heavy beats infantry and vehicles, tank beats infantry, recon beats infantry but loses to heavy, etc.) |
| 🌲 **Terrain effects** | All terrain is CSS-drawn: Forest +20% DEF · Mountain +40% DEF (vehicles blocked) · River impassable (fords passable) · City/Factory +30% DEF · HQ +40% DEF, owned buildings heal 2 HP per turn |
| 🚩 **Building capture** | Advance Wars-style capture: cities/factories/HQ, only infantry/heavies/engineers can capture (engineer 1.5×), stand on a building and wait to build progress (progress = current HP × multiplier, 20 to capture, progress resets when leaving); captured buildings fly your flag and can be taken back; **capturing the enemy HQ wins instantly, losing your own HQ means defeat** |
| 🔧 **Support units** | Engineer auto-repairs adjacent vehicles +3 HP (waiting in place works too); medic auto-heals adjacent infantry/engineers +4 HP (waiting in place works too); both have very low ATK (engineer 2 / medic 1) |
| 💰 **Economy & production** | Owned buildings grant income every turn (+50 each, starting funds 300); click your empty factory to open the production menu and spend funds on new units (they wait this turn); the enemy saves money and builds too |
| 🛡️ **Heavy anti-vehicle** | Heavy infantry deals 1.5× damage to vehicles (recon/artillery/tank/rocket) — infantry can fight armor |
| 💥 **Combat system** | 90% hit chance, 12% crit (×1.5), 0.7× counterattack, damage scales with remaining HP; cannon/rocket cannot fire after moving and never counterattack |
| ⬆️ **Leveling** | Gain XP from combat (support units: capture +8, repair/heal +6); XP needed rises each level (30/40/50/60) for a smooth curve; level up grants +1 ATK, +1 DEF, +2 HP and heals 3 HP (cap Lv.V, excess XP converts to healing) — enemies level up too! |
| 🔍 **Inspect enemies** | Click an enemy unit to see its move range (translucent blue) and attack range (dashed orange) — know your enemy |
| 🤖 **Enemy AI** | Heuristic AI evaluating damage, kills, terrain and danger; cannon keeps distance 3, rocket keeps distance 4 |
| �️ **Move path preview** | Hover to see the move path with direction arrows after selecting a unit |
| 🔊 **Sound & BGM** | WebAudio chiptune SFX (per-unit attack/move sounds, crit, destroy, level-up, capture, etc.) + dual-theme BGM: upbeat march for the player, tense minor for the enemy, auto-switching with turn phases (mutable) |
| 📜 **Battle log & unit cards** | Real-time combat log (player blue / enemy red) and detailed unit info panel |
| 🌐 **Bilingual UI** | Choose 中文/English in the main menu (default Chinese); the whole UI translates instantly |
| 📖 **In-game help** | Unit stats table, color legend, terrain effects and combat rules |

## 🎮 How to Play

1. **Goal**: Destroy all enemy units, or capture the enemy HQ (complete the capture while standing on the enemy HQ tile)
2. Click your unit → click a **blue tile** to move → click a **red tile** to attack; click your empty factory to **build new units**
3. Click **End Turn** when done; the enemy AI then acts

> 💡 Forest/mountains grant defense bonuses but slow movement — each unit type has different move costs per terrain (infantry excel in mountains, treads cannot enter mountains); owned buildings heal 2 HP per turn and grant +50 income; cannon/rocket cannot fire after moving — they must wait in place to fire; heavy counters vehicles.

## 🚀 Getting Started

**No build, no install:**

```bash
# Option 1: just open the file
index.html

# Option 2: serve locally
python -m http.server 8765
# then open http://localhost:8765
```

## 📦 Tech

- Pure HTML + CSS + JavaScript (**zero dependencies**, no frameworks, no build step)
- **Single-file architecture**: all styles and scripts (config / i18n / SFX / logic) are embedded in `index.html` — just open and play, no external files needed
- Runs in any modern browser — double-click `index.html` works too (no ES modules / fetch, file:// friendly)
